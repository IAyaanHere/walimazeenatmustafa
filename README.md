# Noor Invites - Zeenat & Mustafa Walima

A beautiful, cinematic, and fully localized frontend invitation template.

## Features
- Fully local execution (no remote asset dependencies)
- Interactive Scratch Card and Petals UI
- Background Music support
- Clean, customizable config in src/config.js

## Deployment
1. Ensure all assets are pushed to Git.
2. Deploy directly to Vercel/Netlify. No build step required as it's static HTML/JS/CSS.
